# Dependencies

| What | Where |
| --- | --- |
| Third-party code of pvmon, with license texts | [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md), also in each release archive and container image |
| All dependencies of the repository (Go and npm) | [Dependency graph](https://github.com/dombyte/pvmon/network/dependencies) |
| Software bill of materials of the Go modules in a release | The `.sbom.json` files of the [release](https://github.com/dombyte/pvmon/releases) |

`THIRD_PARTY_NOTICES.md` does not list the packages of the documentation site. The
dependency graph shows them from `docs/package-lock.json`.
