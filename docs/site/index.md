# pvmon documentation

pvmon is a self-hosted monitor for photovoltaic (PV) systems. It reads inverters,
batteries, meters and wallboxes. It shows the electricity flow of a household.

pvmon only reads from the devices. It does not control them and it does not calculate
costs. It sends no data to the internet.
